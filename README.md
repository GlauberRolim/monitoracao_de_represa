# 🌊 Sistema de Alerta da Represa

Este é um script simples em **Python** projetado para simular o monitoramento e o alerta do nível de água de uma represa.

---

## 🚀 Como Funciona

Ao executar o programa, o fluxo de funcionamento segue os seguintes passos:

1. **Limpeza do Terminal:** O script limpa o console automaticamente para exibir as informações de forma clara.
2. **Exibição do Cabeçalho:** Mostra mensagens de inicialização e de ativação do sistema de monitoramento.
3. **Simulação do Nível de Água:** O programa escolhe aleatoriamente um entre cinco níveis de capacidade da represa (usando o módulo `random`).
4. **Alerta:** Exibe no terminal a situação sorteada.
